# v3.0.0 — React + shadcn/ui WebUI rewrite

> 2026-06-25 · 32 commits since v1.1.0 · the management panel is now a proper SPA

This release replaces the entire management panel. The old vanilla
HTML + JS dashboard that shipped in v2.2.0 is gone; in its place is a
Vite + React 18 + TypeScript + shadcn/ui single-page app, with four
new pages, real charts, a streaming Playground, and a light/dark
theme.

The v2.0.0 baseline (anti-detection + admin hardening from
**@nianshou**) and the v2.2.0 production-hardening + bug fixes are
preserved unchanged. v3.0.0 is additive: the FastAPI server still
serves the same `/v1/*` and `/admin/api/*` endpoints; the only
breaking change is the location of the bundled webui (`webui-new/dist/`
vs. `webui/`).

---

## Highlights

### Frontend (v3.0.0)

- **Vite + React 18 + TypeScript** SPA with proper code-splitting.
  Production build is **~245 KB gzipped** total (react-vendor 67 KB,
  app 71 KB, recharts 107 KB).
- **shadcn/ui** + Radix UI + Tailwind CSS — full keyboard
  accessibility, ARIA correct, animations via Radix `data-state`.
- **Light + dark + system** themes with one-click switcher, persisted
  in `localStorage`. `prefers-color-scheme` is honoured by default.
- **Recharts** for the new dashboard trend charts (request volume
  + average latency, both over a 30-minute rolling window).
- **react-router-dom v6** with nested routes, protected by a
  `<RequireAuth>` boundary; 401 from the API auto-logs out and
  redirects to `/login`.
- **Zustand** for cross-component state (auth, theme); React state
  for everything else. No React Query — the app is small enough that
  a 50-line `useApi` hook is sufficient.
- **lucide-react** icons (replaces the hand-rolled inline SVG set).
- **Collapsible sidebar** + responsive top bar. Below 1024 px the
  sidebar collapses to icon-only.

### New pages

| Route | Page | Notes |
|-------|------|-------|
| `/login` | Sign-in card | Centered, gradient backdrop, password show/hide, Enter to submit. |
| `/` | Dashboard | 6 stat cards + 2 trend charts (Recharts AreaChart + LineChart with p95 reference) + pool status card with stacked progress bar + token + percentile breakdown + per-model table. |
| `/accounts` | Account pool | DataTable with state badges, error counts, copyable token previews; "Add" opens a Dialog; "Edit" reuses it; row click opens a Drawer with full detail. "Delete" uses a destructive AlertDialog. |
| `/accounts/:id` | (route) | Currently the same as `/accounts`; the Drawer handles the detail UX. |
| `/playground` | Playground | Streaming `/v1/chat/completions` client. System prompt, temperature slider, thinking/search switches, model dropdown populated from `/v1/models`, conversation history with auto-scroll, AbortController-driven stop button. |
| `/settings` | Settings | Read-only view of every runtime config: server, security (password strength, encryption, CORS, trusted proxies), account pool, behaviour (model routes, rate limits, session cache TTL), and a full env-var table with `set` / `default` indicators. |
| `*` | 404 | Plain not-found with a button to return home. |

### Backend additions (v3.0.0)

Two new admin endpoints:

- **`GET /admin/api/history`** — returns `{ interval_secs, points: [...] }`
  with 30-second snapshots of `(total, success, failed, avg_latency_ms)`
  for the last 30 minutes. Backed by `stats_history.py` (a background
  thread + bounded deque, no disk persistence).
- **`GET /admin/api/env`** — returns a typed view of every env var
  the webui Settings page renders, with `set` / `default` indicators
  and secret masking (`***`) for the admin password and the Fernet key.

The existing `start_sampler(get_stats())` runs once at server startup
and never needs user intervention.

### Tooling

- **`webui-new/`** is the new project root. `npm install` (or
  `pnpm install`) + `npm run build` produces `webui-new/dist/`,
  which FastAPI serves at `/webui/...` (with SPA fallback to
  `index.html` for client-side routes).
- **`webui-new/scripts/build.sh` / `build.bat`** — one-shot build.
- **Vite dev server** on `localhost:5173` with proxy rules for
  `/admin/api` and `/v1/*` to `localhost:8080`. Dev workflow:
  `npm run dev` in one terminal, `python -m uvicorn server:app --port 8080`
  in another.
- **CI** now has a `webui` job (Node 20, `npm ci && npm run build`)
  that uploads the `webui-new/dist/` artefact for inspection.

### 2. Backend additions

#### `stats_history.py` (~70 lines)

A new module that:
- Defines a `StatsHistory` class — a thread-safe `deque(maxlen=60)`
  of `(ts, total, success, failed, avg_latency_ms)` tuples.
- Spawns a daemon thread (`start_sampler(stats)`) that snapshots the
  live `StatsSnapshot` every 30 seconds (configurable via
  `STATS_HISTORY_INTERVAL_SECS`).
- Exposes `get_history().points() -> list[dict]` for the
  `/admin/api/history` endpoint.

The sampler is started once at server import time in `server.py`
(right after the `get_pool()` call). It swallows snapshot errors so
it can never die.

#### `GET /admin/api/history`

```json
{
  "interval_secs": 30,
  "points": [
    {"t": 1719372030, "total": 1234, "success": 1200, "failed": 34, "avg_latency_ms": 320},
    ...
  ]
}
```

#### `GET /admin/api/env`

Returns a typed config snapshot for the Settings page. Secret
values are masked to `***`:

### 3. `server.py` static-serve update

- Old: served from `webui/` (vanilla).
- New: prefers `webui-new/dist/` (React build output); falls back to
  `webui/` for backwards compatibility if the React build hasn't run
  yet (e.g. fresh clone + `pip install -r requirements.txt` only).
- SPA fallback: any unmatched `/webui/...` path returns the
  `index.html` so `react-router-dom` can take over.
- 404-on-build-missing is now a friendly JSON error that points the
  operator at `npm run build` in `webui-new/`.

### 4. CI changes (`.github/workflows/ci.yml`)

Added a fourth job `webui` that runs on the same `push` / `pull_request`
triggers. It checks out the repo, sets up Node 20, runs `npm ci` (or
`npm install` if there's no lockfile yet), runs `npm run build`, and
then asserts the existence of `dist/index.html` + `dist/assets/`. The
build output is uploaded as a `webui-dist` artefact for debugging.

The existing `smoke`, `unit`, and `e2e` jobs are unchanged.

### 5. Deletion of the old `webui/`

The four legacy files (`app.js`, `index.html`, `style.css`,
`favicon.svg`) are removed. Operators that have already built the
React webui (`webui-new/dist/`) are unaffected; operators that
have not yet run `npm run build` will see a friendly error pointing
them at the build command.

### 6. New `package-lock.json`

Committed alongside the source so the CI build is reproducible. The
lockfile pins React 18.3.x, Vite 5.4.x, Tailwind 3.4.x, Recharts
2.13.x, Radix 1.x, Zustand 5.0.x, etc.

## Upgrade notes

- **No backend API change.** All v2.x endpoints behave identically.
- **The old `webui/` is gone.** Make sure `webui-new/dist/` is built
  before deploying:
  ```bash
  cd webui-new
  npm ci
  npm run build        # → webui-new/dist/
  # Or use the one-shot script:
  bash scripts/build.sh        # Unix
  scripts\build.bat            # Windows
  ```
- **New dev workflow** (recommended):
  ```bash
  # Terminal 1
  python -m uvicorn server:app --port 8080
  # Terminal 2
  cd webui-new
  npm run dev
  # Open http://localhost:5173
  ```
  The Vite dev server proxies `/admin/api` and `/v1/*` to
  `localhost:8080`, so CORS is never an issue.
- **No new Python dependencies.** The two new admin endpoints are
  pure-Python and ship in the existing `stats_history.py` module.
- **Theme preference** is stored under `localStorage` key
  `ds2api-theme`. The auth token is stored under `ds2api-auth`.
  Both keys are local to the browser and never leave the device.
